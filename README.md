# Todo Notes App (React)

A simple and clean Todo Notes application built using React.
This app allows users to create notes and manage tasks efficiently.

---

##  Features

* ➕ Add new notes (title + description)
* 📋 Display notes in card format
* 🧠 Simple and clean UI
* ⚡ Built with React functional components & hooks

---

## Tech Stack

* React.js
* JavaScript (ES6)
* Tailwind CSS
* Vite

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

# Clone the repository

git clone https://github.com/nikhiljangra03/Todo-Website

# Install dependencies

npm install

# Start development server

npm run dev
